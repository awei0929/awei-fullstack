## 实现

- `ChatMarkdown({ content })` 复用已有 `react-markdown`、`remark-gfm`；段落、标题、列表、引用、行内代码、GFM 表格与围栏代码均使用真实组件渲染。没有新运行依赖、图标库或高亮库。
- 原始 HTML 关闭；URL 只接受 HTTP(S) 与解码后只含字母/数字/下划线/连字符的站内片段，拒绝危险协议、协议相对地址、普通相对路径和附件路径。外链 `noopener noreferrer`；不会执行模型 HTML。
- 图片始终显示替代说明及“未自动加载”，不生成图片、媒体或 iframe 元素。链接包图片仍只产生外层正常链接，避免嵌套交互元素。未扩展附件、上传或远程图片加载功能。
- 代码块显示语言（缺省“代码”）和复制按钮；未闭合流式围栏按代码块渲染。代码与表格在各自容器滚动并可键盘聚焦；正文 16px/1.8，辅助文字至少 12px。使用深橄榄/暖奶油/暖橙及细线，无渐变/光晕/大阴影。
- `ChatCopyButton({ text, label?, className? })` 仅在点击时调用 `navigator.clipboard.writeText`。精确保留传入文本，不读取剪贴板；不可用、不安全上下文或权限拒绝返回可见失败说明。重复点击受保护，成功反馈后复位；卸载清理复位计时器并忽略迟到结果。可见焦点与 `role=status` 反馈已接入。
