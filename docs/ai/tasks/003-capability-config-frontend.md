## 独立审查后的 P2 修复

- 根浏览器复现：清空 AI 昵称后切换前端 Tab，再保存时原生校验命中隐藏的 required 输入，但没有切回或聚焦；离开能力分区时无效昵称也不在当前 DOM 中。根授权扩展 `admin/index.tsx` 的保存定位流程。
- 修复：保存前按固定类别顺序检查共享草稿的所有能力昵称，发现无效项就切回「我的能力」、对应受控 Tab 和手机编辑面板，React 渲染后的下一帧聚焦对应输入并调用原生提示。Tab 继续保留草稿和面板内容，关闭切换动画以保证聚焦时目标已显现；能力有效时仍执行原有表单校验与保存。
- `/tmp/nest-capability-validation-check.mjs` 执行实际 AdminPage：先红，原结果停留 `home`；修复后 7 项通过。覆盖其它分区定位、隐藏 AI Tab、渲染后聚焦/提示、重复保存定位、手机预览回编辑、纯空白与 41 Unicode 字符拒绝、40 Unicode 字符正常保存以及其它分区原生校验保留。该模拟不替代根的实际 DOM 与浏览器复验。
- 根同时实测从手机技术列表区域横向滚动无法传递给外层横卡，原因是内部 `overscroll-behavior: contain` 同时阻止两个轴。技术列表改为 `overscroll-behavior-y: contain` / `overscroll-behavior-x: auto`，保留局部纵向滚动与父级场景触摸隔离，允许横向滚动链到卡片容器。真实横向链由根复验，不声称本子任务已测真实手机触摸。
