## 问题与改动

原预览以1040px嵌套div承载公开页，CSS的vw/vh/media与JS的matchMedia却读取1889/1920px后台窗口。宽框不放大导致右侧空白；560px框承载720px舞台且两层overflow:auto，标题和卡片按错误视口计算而断行/越界。浏览器红证据为框1220×560、画布1040×560、内容720高、标题两行、部署卡越界。

- 新增admin/site-preview、preview-page、preview-protocol、preview-geometry和独立Less模块。真实同源iframe在/admin/preview启动自己的React与JS realm，父草稿经来源/window校验后在内存同步。空文案、空昵称可连续预览，错误结构不覆盖已有草稿；不将草稿写入URL/存储或API。
- 后台index替换本地Preview，router接独立预览路由。桌面画布至少1440×900，宽区域等比增加；手机390×844，窄区域缩小、宽区域居中；外框与变换后的iframe精确同尺寸。
- 删除后台旧previewFrame/previewScale及手机限高；清理公开样式旧preview尺寸覆盖及5个专属container块。公开页字号/卡片/人物/光圈规则保留，preview只约束根高度/裁剪与header位置。保留必要的名单和阅读面板滚动及外层正常纵向滚动。
