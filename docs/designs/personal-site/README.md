## 交互设计意图

- 首屏：鼠标触发视线和轻微转头，离开后自然回正；文字与导航保持稳定可读。
- 滚动：镜头拉远，角色进入坐姿，作品档案成为主要交互对象；滚动停下时保持可读构图。
- 档案：悬停抬起与展开页签，点击后选中页变成案例展台；关闭回到之前位置。
- 案例：人物退到边缘，内容获得主导面积；保留直接访问内容的导航。
- 手机与减少动态：保持相同内容顺序，替换鼠标追视，采用稳定关键帧与简化衔接；具体窄屏稿尚未完成。

## 设计阶段边界（历史）

`HEY.`、问候语和案例图均为设计占位，不是用户确认的品牌名、项目内容或真实数据。配置页画的是登录后的状态，登录页和异常状态还需补齐。尚未设计完整作品详情、移动端和最终联系场景。

本轮没有修改 frontend/ 或 backend/ 的任何代码，也没有初始化站主账号、修改数据库、构建或部署新页面。

## 开发前流程复核（2026-11-07）

用户选用现有立体角色方案，先实现页面和后台，人物动作素材后补。第二轮公开/后台独立审查明确两个滚动主场景和作品阅读子状态；配置全局保存、权限、冲突与手机流程以[实施规格](../../specs/003-personal-site.md)为准。

- 配置页精修：全站保存、固定角色方案、固定场景顺序、未保存预览。
- 公开阅读与手机：作品阅读返回、手机关键页面。
- 登录与异常状态：站主登录、无权限、手机配置、冲突示意。
