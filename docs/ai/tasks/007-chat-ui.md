## 实际修改

- `chat-panel.tsx` / `chat-panel.module.less`：移除历史品牌脚注和常驻“仅站主可见 · 自动保存”，保留正在读取状态，标题区由 72px 收至 64px。空态只保留一个标题与三项原建议入口，删除眉题、重复介绍、操作脚注和外链式箭头，并清理相应样式。
- `chat-turn.tsx` / 共用 Less：以真实模型名作为回复标题，保留 H. 标识；正常完成回复不再显示“已完成”。等待、生成、停止、失败、中断、自动切换来源及错误正文仍按原条件展示。复制、记住、重新编辑入口不变。
- 输入区保留实际备用模型说明、Ctrl / ⌘ + Enter 发送提示、输入标签与完整无障碍键盘说明；移除可见的 Enter 换行说明，字数到 3600 时强调，超过 4000 时沿用错误颜色与原禁发条件。
- `chat-memory-panel.tsx` / `chat-memory-panel.module.less`：将首尾说明收为一条，明确手动保存、启用、发送给所选及备用模型、从后续消息生效。正文优先，启停、日期、编辑与删除归入可换行操作区；保留开关名称、编辑字段标签、错误、超长内容提示及删除确认。
- 没有记忆且编辑器关闭时才显示空态；新建编辑器不再与空态叠加。没有修改 API、store、流订阅、滚动控制、模型选择、持久化或后台外壳。
