## 目标与范围

- 只有普通用户，开放注册；账号是 3–5 位 ASCII 数字字符串，保留前导零（00123 与 123 不同），密码单独设置。
- 登录/注册在同一弹窗通过底部文字链接互相进入，不使用 Tabs/Segmented；注册成功自动登录。Session + HttpOnly Cookie，MongoDB 持久化用户、会话、任务。
- 游客浏览三条只读默认任务，点击创建/编辑/删除打开登录弹窗；登录后仅本人任务，不复制示例。
- 不包含管理员、分享、验证码、邮件/短信、自助找回密码、修改账号、第三方登录、完成切换或部署。
- 后端用于学习NestJS：所有手写后端源码补齐中文注释，解释Nest职责/依赖注入/执行顺序与关键设计理由，测试辅助代码说明隔离和验证目的。
- 用户已授权规格整理、实现、验证与必要修复；保留当前分支，不提交、推送或清空数据库。

## 用户行为

- 保持现有 React/MobX/Ant Design 页面风格。游客页头“登录 / 注册”，明确标记“示例任务”；登录后展示账号与退出入口。
- 登录表单为账号、密码；注册增加确认密码。账号使用文本输入和 numeric inputMode，不用 number 丢失前导零。
- 工程默认：密码 8–64 个 Unicode code point（Array.from(value).length），不 trim、截断或强制字符类别；前后端规则一致，变体选择符也计数。账号拒绝空格、符号、非 ASCII 数字及 JSON 数字类型。
- 工程默认：会话固定绝对有效期 7 天（配置可缩短），无记住我选项。刷新先恢复身份；网络失败显示重试，不误当退出。
- 提交中防重复和关闭；失败保留输入；业务错误使用消息提示，字段格式/确认密码错误显示在输入框旁；成功清除密码、关闭弹窗并切换数据来源。注册失败不建立已登录会话。
- 默认显示登录，底部“还没有账号？立即注册”打开注册，注册底部“已有账号？去登录”返回；不使用顶部标签切换。切换表单清理不适用错误；重名提示“账号已注册”，登录失败统一“账号或密码错误”。
- 游客触发写入只开弹窗，不自动重放示例上的操作；登录后由用户重新操作。
- 登录、退出、会话失效时清空上个身份的列表、统计、编辑/删除弹窗和错误。异步成功、失败、finally 及后续统计刷新均按身份版本隔离；旧 401 不得退出新用户。
- 会话过期：移除私有数据、回公共示例并打开登录弹窗说明原因。退出失败显示可重试错误，不谎报服务端已撤销。退出网络请求未结束时，即使旧私有请求返回401，也不能开始新登录，以免迟到退出响应清除新Cookie。

## HTTP 与数据契约

路径统一带 /api；沿用现有异常 statusCode/message/path/requestId 与 X-Request-Id。成功不统一包装 data。
User = `{ id: UUID, account: string }`；SessionView = `{ user: User | null, csrfToken: string }`。

| 方法 / 路径                                    | 输入与权限                                      | 成功                                       | 失败                                             |
| ---------------------------------------------- | ----------------------------------------------- | ------------------------------------------ | ------------------------------------------------ |
| GET /auth/session                              | 恢复或初始化匿名 CSRF 会话                      | 200 SessionView                            | 存储故障是服务错误，不能伪装成未登录             |
| POST /auth/register                            | JSON { account, password }；会话及 X-CSRF-Token | 201 SessionView，重建 Session ID，自动登录 | 400 输入；409 重名；403 CSRF；429 限流           |
| POST /auth/login                               | JSON { account, password }；会话及 X-CSRF-Token | 200 SessionView，重建 Session ID           | 400 格式；401 凭据；403 CSRF；429 限流           |
| POST /auth/logout                              | 当前会话及 X-CSRF-Token                         | 200 { success: true }，销毁会话、清 Cookie | 403 CSRF；存储失败不能成功                       |
| GET /public/tasks                              | 无                                              | 200 固定示例 Task[]                        | 不读取真实任务集合                               |
| GET /public/stats                              | 无                                              | 200 { total: 3, uptimeSeconds }            | 与示例数量一致                                   |
| GET /tasks、GET /stats                         | 已登录                                          | 保留原形状，仅本人数据                     | 401 未登录/过期                                  |
| POST /tasks、PUT /tasks/:id、DELETE /tasks/:id | 已登录及 X-CSRF-Token                           | 保留原成功状态与 Task                      | 401 身份；403 CSRF；400 输入；404 无任务或非本人 |

- 私有路由先认证再校验写入 CSRF，之后 DTO/路径管道；解析错误 JSON 仍可能更早 400。
- DTO 拒绝额外字段（包括 ownerId、userId、role），响应不泄漏密码哈希、Mongo \_id、会话凭据。
- session/register/login 返回当前 csrfToken；前端写入通过 X-CSRF-Token 携带。随机令牌绑定 Session，常量时间比较；会话换 ID 时换令牌。覆盖注册、登录、退出及所有任务写入。
- 个人/认证响应 Cache-Control: no-store；继续相对 /api 与 Vite 代理，不开放宽泛 CORS。SameSite 不替代 CSRF。
- 用户：UUID id、唯一 account、passwordHash、createdAt/updatedAt；并发重名由唯一索引保证只能一个成功。Argon2id 参数至少 memoryCost=19456 KiB、timeCost=2、parallelism=1。
- 使用 express-session + connect-mongo，复用 Nest/Mongoose 当前连接对应的 MongoDB；测试不得连接开发库保存会话。SESSION_SECRET 固定配置，缺失/少于32字符启动失败；本地开发配置随机值、不进入 Git。
- Cookie nest.sid，HttpOnly、SameSite=Lax、Path=/、无 Domain，生产 Secure=true。代理信任显式配置，不无条件信任转发 IP。
- Session 保存 userId、csrfToken、authExpiresAt；认证每次检查绝对期限，TTL 仅清理。退出后旧请求不得重新保存有效已撤销会话。应用重启、存储和密钥不变时有效登录可恢复。会话保存失败须清理本次新会话并阻止响应结束时隐式重试保存，不能返回失败却建立登录。
- 限流默认：登录/注册合计每 IP 15 分钟30次；登录另每账号15分钟10次；429 带 Retry-After。MongoDB 原子计数、过期清理，不信任任意 X-Forwarded-For；合法正数配置允许测试小阈值。
- 任务增加 ownerId，创建从会话取得；列表/count/原子修改/删除均过滤 ownerId。公开 Task 结构不变；索引支持 ownerId/createdAt/\_id 排序。
- 公共示例三条，稳定 UUID 与日期，completed=false；独立常量，每次返回新对象。个人新账号初始空列表。

## 方案与决策

- 用户选择 Session；相比 JWT + Refresh Token，当前单后端浏览器应用可直接管理退出/过期，代价为每请求查共享存储。
- 已确认仅普通用户、弹窗、数字短账号、自行注册、自动登录、游客默认数据只读、无验证码。保留现有技术栈，不引入 Redis 或新前端测试框架。
- 同弹窗切换、保留前导零、不自动复制公共数据已向用户说明并得到“没有问题开始执行”。密码规则、期限、CSRF、限流及旧无主数据隔离为实现者工程默认。
