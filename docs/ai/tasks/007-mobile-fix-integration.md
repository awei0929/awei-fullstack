## 实现

导航整体层级高于能力卡；手机欢迎文案及探索按钮改为自然流，移除820px强制舞台及按钮500px固定偏移，以至少640px/视口和内容高度布局。稳定能力场景不再保留长欢迎文案高度。预览内部可纵向滚动，固定阅读弹窗沿用居中布局。

手机主要关闭、菜单、场景控件扩大至44px；任务创建表单单实例提前，桌面仍列表左/创建右，动作行独立、按钮至少44px、间隔8px。删除公开页重复英文眉题与泛化介绍、后台不可操作色板，手机隐藏登录装饰舞台和常驻快捷键视觉提示。独立上传页仅一份完整公开性声明，复用入口默认保留公开提示；格式、大小、保存生效、记忆发送范围和无障碍说明保留。
