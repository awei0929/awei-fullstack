## 公开数据

Task 响应字段：

| 字段 | 约定 |
| --- | --- |
| id | 服务端生成的 UUID v4，编辑时保持不变 |
| title | 字符串，输入 trim 后长度 1–120 |
| completed | 布尔值，创建默认为 false；当前无修改入口 |
| createdAt | 创建时间的 ISO 字符串，编辑时保持不变 |

MongoDB 内部 _id、updatedAt 不进入公开任务响应。列表按 createdAt、_id 升序查询。
数据持久化至 MongoDB；后端重启不清空任务。数据库卷被删除不属于“正常重启保留数据”的保证。

## HTTP 契约

所有路径带 /api 前缀。POST/PUT/DELETE 使用公开演示请求头 `X-Learning-Key: awei-learning`；GET 无此要求。
该值不是用户凭据，不提供正式身份认证。

| 方法 / 路径 | 输入 | 成功响应 |
| --- | --- | --- |
| GET /api/tasks | 无 | 200，Task[] |
| POST /api/tasks | JSON { title } | 201，创建的 Task |
| PUT /api/tasks/:id | UUID v4 路径 id；JSON { title } | 200，更新后的 Task |
| DELETE /api/tasks/:id | UUID v4 路径 id | 200，被删除的 Task |
| GET /api/stats | 无 | 200，{ total: 非负整数, uptimeSeconds: 非负整数 } |

- 对已匹配的任务写入方法，缺失或错误的演示头返回 403，先于 DTO/路径参数管道。
- 守卫放行后，非法 UUID、缺失/null/非字符串/空白/过长标题、额外请求字段返回 400。
- PUT 只修改 title；请求体重复传 id，或提交 completed、createdAt 等额外字段均不接受。
- 守卫放行且输入合法时，编辑/删除不存在的任务返回 404，message 为“任务不存在”。
- PUT/DELETE 缺少路径 id 不匹配路由，返回 404。错误 JSON 在解析阶段返回 400，不应误解为所有错误都先过 Guard。
- 被拒绝的写入不修改已有任务或统计；编辑不改变任务数；创建/删除分别增减任务数。
- 错误体包含 statusCode、path、requestId；当前常见 HTTP 错误的 message 为字符串或字符串数组，error 等原字段可保留。
- 错误响应头 X-Request-Id 与响应体 requestId 一致。未知异常返回 500 与通用消息，内部详情留在后端日志。
- 成功响应保持上述原始业务结构，不额外套一层 data。

## 前端行为

依据：[API](../../frontend/src/api/tasks.ts)、[Store](../../frontend/src/store/tasks.ts)、[页面](../../frontend/src/pages/tasks/index.tsx)。

- 查询、创建、编辑标题、删除；删除需确认，取消不发删除请求。
- 写入进行中避免重复提交，失败显示错误并保留可重试状态。
- 删除成功使用响应任务的 id 更新列表，因此依赖删除返回 Task 的契约。
- 创建/删除后重新查询统计，刷新列表同时刷新统计；统计失败显示未知值，不冒充 0。
- 运行时长展示最近一次统计响应的值，不是浏览器实时计时器。
- 完成状态当前固定展示待完成；列表与统计各自使用请求版本号忽略较早的同类读取响应。完整读写交错行为尚未经浏览器验收，不将其描述为已解决全部并发问题。
