## M-01：P2，矮屏手机菜单被能力卡片遮挡

复现步骤：320×568打开首页，切到“我的能力”，横向滚到“公司项目”，整页下滚至`scrollY=252`，展开导航，点击“进入空间”。预期打开站主入口，实际打开公司项目详情，URL变为`?view=projects`。

实测菜单最后一项边界为`x43.3 / y282.38 / w218.4 / h45.95`，中心点约`(152.5,305.4)`实际命中公司项目卡片；菜单前四项中心均命中自身。卡片顶部此时为Y296。390×568、相同滚动位置再次核对，入口中心仍命中项目卡。通过键盘Enter激活同一菜单项能正常打开站主面板，排除了入口处理函数跳错页面的原因。

原因：[`site/style.module.less`](../../../frontend/src/pages/site/style.module.less)第54行header层级5，第218行菜单层级7被限制在header内部，第324行手机header固定；[`capability-content.module.less`](../../../frontend/src/pages/site/capability-content.module.less)第1行能力卡片在外层层级7，手机第26行允许指针事件，卡片滚到菜单区域后盖住导航。`openLogin`（`site/index.tsx:192`）仅关闭菜单并打开登录。

建议优先调整导航与舞台的整体层级关系，确保展开导航始终处于卡片上方；后续验证须覆盖320/390宽、568高、下滚后所有菜单项与横向卡片，而非只检查首屏。此缺陷本轮未修复。
