# SPEC-007 前端信息精简与交互打磨

- 状态：已上线并验证。
- 更新：2026-11-14；功能提交 `0b04b19`，部署与线上只读核验完成。
- 依据：用户要求按 AGENT 的 UI/UX 原则检查当前前端，去掉不必要辅助标签与说明，打磨布局与交互。
- 关系：补充 SPEC-001/003/006 的页面呈现约定；本次明确的文案精简替代旧规格对应的装饰性文案，不改变原业务合同。

## 目标与范围

检查公开官网、能力详情、登录、站主管理（含预览、能力/附件编辑）、AI 对话与记忆、任务清单。减少重复标题、英文眉题、口号和对显而易见操作的说明，用层级、分组、留白、选择状态与靠近内容的操作表达使用方式。

沿用 React/MobX/Ant Design/Less Modules 和现有视觉：官网橄榄舞台、奶油文字及人物；后台沿用现有编辑器；聊天保留深导航与纸白阅读区。本次为精修，不换品牌、图片、字体或动效方案，不更改用户内容、API、持久化或模型逻辑。2026-11-14 用户在本地验收完成后追加授权提交、推送与部署，沿用已有验证并跟进现有自动发布流程。

方向：服务个人官网访客与站主；气质安静、亲切、清楚；材质沿用纸张与橄榄舞台；视觉重点留给人物、真实履历与对话正文；保留 HEY. 品牌和现有选中标记，不增加新装饰。

## 检查结论与设计选择

1. 后台标题口号、LIVE PREVIEW、草稿统一保存脚注重复；删去，保存按钮用“保存并更新官网”，预览标题依脏状态变化。已保存与未保存状态始终可辨。
2. 首页编辑器中角色素材/场景介绍与实时预览重复；减少无操作的展示模块。保留所有真实字段，分组间距清楚，必要格式/公开范围/上传限制就近说明。
3. 官网能力详情英文眉题/口号/目录说明与标题重复；精简头尾和目录，保留用户正文、可见性、关闭/切换、焦点与移动横滚。登录减少装饰英文与脚注，保留表单标签和错误。
4. 聊天空态、历史品牌脚注、完成状态重复；保留一个空态标题与现有建议入口，减少常驻辅助行。模型实际状态、失败/中断/停止/自动切换必须清楚。记忆范围用一句有效说明，卡片依布局区分内容、启停和操作。
5. 任务清单移除口号/重复提示；统计仍来自后端，列表数量不冒充统计；以紧凑标题统计区与创建区呈现，访客示例与私有任务区分保留。

采用现有页面内的有针对性精简，避免仅删除文字后留下空壳；不做全局重设计。变更为可逆的文案与布局调整，采用类型/lint、已有相关回归及真实浏览器验证，不为静态标签新增镜像测试；如发现实际业务缺陷则单独复现验证。

## 行为与兼容性

- 正常：既有入口、字段、发送/停止、保存、目录、预览均可用；表单标签可访问，键盘焦点可见。
- 加载/错误/空态：保留真实状态、重试、校验及恢复路径；不靠删除提示掩盖失败。
- 草稿/重复操作：原保存互斥、未保存保护、聊天流状态、记忆编辑边界保持。
- 接口、数据模型、迁移：不涉及；测试使用独立本地合成环境，不写生产数据。

## 验收条件

- AC-01：公开能力详情/登录去除重复装饰文字，目录可切换且选中明确，关闭返回与键盘焦点保持，用户内容未丢失。
- AC-02：后台移除重复标题副文案/预览脚注；表单、预览、保存状态形成清楚分组，编辑后状态变化，切区草稿保留，未保存离开仍拦截。
- AC-03：聊天/记忆减少空态与重复说明，历史/搜索/建议、发送与停止、错误/切换状态、记忆编辑/启停可使用；完成回复无冗余状态堆叠。
