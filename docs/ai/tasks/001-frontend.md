## 实现选择

- 背景：身份变化可能与多个旧请求交错。选择显式捕获 identityVersion 和 CSRF token，Store 不使用全局 401 回调；理由是旧错误也必须验证发起身份。影响：所有请求回调和写入后的统计刷新统一遵守同一边界。
- 背景：退出、会话过期销毁或失去有效 CSRF 会话。选择下一次认证前缺 token 时调用 session 初始化匿名 token；遇到认证 / 退出 403 清除 token 并明确提示再次提交。正常退出成功立即显示公共示例，不因额外 session 初始化失败假报退出失败。
- 背景：页面局部表单不应残留上一身份。选择用身份版本重建任务工作区；登录弹窗不重放游客操作。认证成功 / 关闭会清除密码。
- 背景：当前项目无前端 test 脚本且禁止为技能引入框架。沿用现有 lint/build，额外用已有 Rolldown + Node assert 做临时可控响应冒烟验证；不新增框架、依赖或正式测试脚本。浏览器验收由主代理负责。
