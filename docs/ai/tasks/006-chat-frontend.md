## 实现

- 新增 `src/types/chat.ts`、`src/api/chat.ts` 与 `src/utils/sse.ts`。普通 JSON 和流式请求共享 `http.ts` 的同源 Cookie、CSRF 与标准 HTTP 错误解析。API 对模型目录、历史、业务事件及 UUID/时间/长度/终态做运行时校验；仅发送 requestId/content/modelId。
- 流解析处理跨 UTF-8 字节、CRLF/CR/LF、跨块事件、多行 data、注释；未结束事件不派发、单事件有上限；传输 EOF 和原始 `[DONE]` 均不能冒充业务完成。校验 start/delta/done 顺序及会话/请求标识，异常释放读取器。
- 新增 MobX `ChatStore`，独立管理模型、会话、输入、流及错误；身份、详情读取、活动运行分别隔离旧响应。受理前保留输入，确认 start 后清空；重复提交/生成时切模型受锁约束。停止按取消接口终态展示，停止中的迟到 done 不覆盖取消结果；意外 EOF 保留部分正文并查询已保存终态。历史 streaming 轮可停止；初次创建尚未结束时停止不会继续启动生成。
- 当前 401 清除聊天并触发登录；旧身份 401 忽略。站主 403 清除聊天内容；CSRF 403 保留输入并清除旧 token，后续明确操作重新取 token。503 保留输入并显示服务消息。离开聊天/切会话/身份变化/退出开始会取消旧流，离开页面清理事件与身份监听。
- `/admin` 加“AI 对话”导航及手机分区选项；沿 Ant Design、Less 与橄榄/奶油/橙色样式。会话选择、新对话、后端白名单模型选择、逐段纯文本、明确终态、重新编辑、字数计数、Ctrl/⌘+Enter、停止、重试读取均已接入。聊天视图不挂载官网编辑/iframe，官网草稿仍由原 SiteAdminStore 持有；返回编辑继续原草稿。
