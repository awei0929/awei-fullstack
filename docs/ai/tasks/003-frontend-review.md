1. **[P1 → 已关闭] 连续编辑时未保存预览停在第一笔。** 原 `SiteExperience` 和 `ProjectImage` 没有 MobX observer；父级仅因 dirty 从 false 变 true 重渲染，后续草稿字段变化没有订阅。整合者真实浏览器先后输入 `HELLO. FIRST` / `HELLO. SECOND`，修复前标题仍为 FIRST，修复后立即为 SECOND，已恢复原内容且 dirty 清除。当前 `site/index.tsx:55,83` 两组件均已包装 observer；整合者另确认仅改 coverUrl 至 `/site/task-cover.jpg` 时预览 img.src 即时更新，随后还原原上传 URL，dirty 为 false。浏览器红/绿由整合者执行，本代理只做源码窄复核。
2. **[P2 → 已关闭] 手机菜单来源的焦点恢复。** 原 openPanel 收起菜单后，returnFocusRef 指向 `display:none` 的关于/联系按钮；仅 `isConnected` 检查不能保证其可聚焦。当前 `site/index.tsx:127–139` 检查 `getClientRects()`，隐藏来源回退可见菜单按钮；直接 URL 仍回档案标题。整合者真实手机浏览器已确认菜单→关于→关闭后焦点为可见的“打开导航”，并确认项目阅读/back 恢复项目按钮且页面无横向溢出。本代理未执行浏览器。
3. **[P2 → 已关闭（源码窄复核）] 关于/联系将首次请求失败描述为空资料。** 原资料分支没有使用 loading/error；首次加载失败时 welcomeContent 的空字段被描述成未公开。当前 `site/index.tsx:300` 对 welcomeContent 首次未成功的所有阅读面板统一显示加载或失败/重试，真实成功空资料才显示空态。本代理核对条件和 JSX 路径，不将此源码复核称为浏览器失败模拟测试。
