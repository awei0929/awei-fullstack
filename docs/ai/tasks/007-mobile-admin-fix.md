## 改动

- 登录在不超过 720px 时直接显示操作内容，删除原 126px 手机装饰舞台样式；关闭按钮为 44×44px，标题留出关闭位置，切换账号操作最小高度 44px。保留桌面舞台、登录/恢复/错误逻辑与焦点管理。
- 外观页删去不可操作的“空间风格”、静态色板与三行死样式，动效和音乐字段未改。
- 聊天在 `hover: none`、`pointer: coarse` 或宽度不超过 760px 时仅视觉隐藏快捷键说明；原 `chat-input-hint`、`aria-describedby` 和 Ctrl/⌘+Enter 处理均保留，字数仍靠右。历史抽屉关闭按钮至少 44×44px。
- 独立上传页只在顶部保留完整公开说明，包含隐藏项目/移除引用不会转私密；复用控件默认继续展示上传即公开。成功结果不再重复“文件已公开”，独立页保存生效说明仅保留底部一份；类型、大小、进度、错误及正文插入提示保留。
- 手机记忆面板关闭、添加、编辑、删除、确认和编辑器按钮最小 44px，编辑/删除间隔 8px；记忆发送范围说明与业务状态不变。
